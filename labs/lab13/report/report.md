## Контрольные вопросы

**1. В каких случаях следует использовать статическую маршрутизацию? Приведите примеры.**  

Статическую маршрутизацию следует использовать в тех случаях, когда структура сети является относительно простой, стабильной и не требует частого изменения маршрутов. При статической маршрутизации администратор вручную указывает маршруты на сетевом оборудовании, поэтому такой способ хорошо подходит для небольших сетей или отдельных участков крупной сети.

Статическую маршрутизацию целесообразно использовать в следующих случаях:

- если сеть небольшая и содержит ограниченное количество маршрутизаторов;
- если маршруты между сетями заранее известны и редко изменяются;
- если нужно настроить маршрут по умолчанию для выхода во внешнюю сеть;
- если необходимо вручную задать резервный маршрут;
- если требуется полный контроль над направлением передачи трафика;
- если использование динамической маршрутизации избыточно для данной сети.

Примеры использования статической маршрутизации:

- подключение локальной сети организации к сети провайдера через один маршрутизатор;
- настройка маршрута из филиала в центральный офис организации;
- подключение отдельной подсети пользователей к основной корпоративной сети;
- настройка маршрута по умолчанию на маршрутизаторе филиала для отправки всего неизвестного трафика в центральную сеть;
- организация связи между несколькими VLAN через маршрутизатор или L3-коммутатор при небольшой и фиксированной структуре сети.

Например, если в сети есть маршрутизатор филиала в г. Сочи, то на нем можно вручную указать маршрут до сетей центрального офиса в Москве. Аналогично на маршрутизаторе центрального офиса можно прописать статический маршрут до сети филиала.

**2. Укажите основные принципы статической маршрутизации между VLANs.**  

Статическая маршрутизация между VLANs используется для организации обмена данными между разными виртуальными локальными сетями. Так как VLAN разделяют сеть на отдельные логические сегменты, устройства из разных VLAN не могут взаимодействовать напрямую без маршрутизации.

Основные принципы статической маршрутизации между VLANs:

- для каждого VLAN создается отдельная IP-подсеть;
- шлюзом для устройств VLAN выступает интерфейс маршрутизатора или L3-коммутатора;
- на маршрутизаторе или L3-коммутаторе должны быть настроены интерфейсы или подинтерфейсы для каждой VLAN;
- каждому интерфейсу или подинтерфейсу назначается IP-адрес из соответствующей подсети;
- на конечных устройствах в качестве шлюза по умолчанию указывается IP-адрес интерфейса своего VLAN;
- между маршрутизаторами при необходимости вручную прописываются статические маршруты до удаленных VLAN-сетей;
- на коммутаторах порты пользователей назначаются в соответствующие VLAN;
- соединение между коммутатором и маршрутизатором или L3-коммутатором обычно настраивается как trunk, если через один физический канал передается трафик нескольких VLAN.

Пример: если в сети есть VLAN 101 для дисплейных классов и VLAN 104 для других пользователей, то для каждой VLAN создается отдельная подсеть. На маршрутизаторе или L3-коммутаторе настраиваются шлюзы для этих VLAN. После этого устройства из VLAN 101 смогут обмениваться данными с устройствами из VLAN 104 через маршрутизирующее устройство.
