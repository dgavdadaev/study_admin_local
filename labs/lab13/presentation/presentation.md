# Цели и задачи работы

## Цель лабораторной работы

Провести подготовительные мероприятия по организации взаимодействия через сеть провайдера посредством статической маршрутизации локальной сети с сетью основного здания, расположенного в 42-м квартале в Москве, и сетью филиала, расположенного в г. Сочи.

# Ход выполнения работы

## Дополнение схемы проекта

В проект были добавлены две новые подсети:

- подсеть основной территории организации в 42-м квартале Москвы
- подсеть филиала организации в г. Сочи

![Общая схема проекта после добавления новых подсетей](Screenshot_1.png){ width=70% }

## Территориальная схема связи

В физической рабочей области Cisco Packet Tracer была построена территориальная схема взаимодействия между площадками Москва и Сочи.

![Территориальная схема связи между Москвой и Сочи](Screenshot_2.png){ width=70% }

## Московский сегмент сети

В московский сегмент сети была добавлена новая площадка основной территории организации в 42-м квартале.

# Первоначальная настройка оборудования

## Состав первоначальной настройки

Для добавленных маршрутизаторов и коммутаторов была выполнена базовая конфигурация.

Основные этапы настройки:

- назначение имени устройства
- настройка консольного доступа
- настройка VTY-линий
- включение пароля привилегированного режима
- включение шифрования паролей
- создание пользователя администратора
- настройка доменного имени
- генерация RSA-ключей
- включение удалённого доступа по SSH
- сохранение конфигурации
