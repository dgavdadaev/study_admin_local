# Цель работы

## Цель

Настроить динамическую маршрутизацию между территориями организации  
с использованием протокола **OSPF** в Cisco Packet Tracer.

# Ход выполнения

## Исходная топология

- Открыт готовый проект корпоративной сети
- В сети присутствуют маршрутизаторы, коммутаторы, серверы и ПК
- Настраивалась связь между Москвой и филиалом в Сочи

![Общая топология сети](Screenshot_1.png){ width=80% }

# Проверка ICMP

## Основной маршрут

- Проект переведён в режим **Simulation**
- Создан ICMP-пакет:
  - источник: **admin-donskaya-dgavdadaev-1**
  - получатель: **sch-sochi-dgavdadaev-pc-1**
- Пакет успешно дошёл до ПК в Сочи

![Прохождение ICMP-пакета по основному маршруту](Screenshot_12.png){ width=85% }

## Отключение VLAN 6

- На коммутаторе провайдера временно отключён **VLAN 6**
- Интерфейс **Vlan6** перешёл в состояние **down**
- Основной канал до Сочи стал недоступен

![Отключение VLAN 6](Screenshot_13.png){ width=85% }

## Изменение маршрута

- После отключения VLAN 6 ICMP-пакет пошёл другим путём
- Трафик был направлен через:
  - **msk-q42-dgavdadaev-gw-1**
  - прямой канал **q42-sochi**
  - VLAN **7**
- OSPF автоматически перестроил маршрут

![Маршрут после отключения VLAN 6](Screenshot_14.png){ width=85% }

## Восстановление VLAN 6

- VLAN **6** был создан повторно
- Интерфейс **Vlan6** включён командой `no shutdown`
- Основной канал связи с Сочи восстановлен

![Восстановление VLAN 6](Screenshot_15.png){ width=85% }

## Возврат на основной путь

- После восстановления VLAN 6 выполнена повторная симуляция
- ICMP-пакет снова пошёл по основному маршруту
- OSPF пересчитал маршрут и выбрал восстановленный канал

![Возврат ICMP-пакета на основной маршрут](Screenshot_16.png){ width=85% }
