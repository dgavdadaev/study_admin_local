## Подключение ноутбука администратора к сети

## Настройка списка контроля доступа для web-сервера

На маршрутизаторе **msk-donskaya-dgavadadev-gw-1** был создан расширенный список контроля доступа для ограничения трафика к web-серверу.

Была выполнена следующая конфигурация:

enable  
configure terminal  
ip access-list extended servers-out  
remark web  
permit tcp any host 10.128.0.2 eq 80  
exit  

Данный список разрешает доступ всем узлам сети к web-серверу с IP-адресом 10.128.0.2 только по протоколу HTTP (порт 80).

![Создание ACL для web-доступа](Screenshot_3.png){ #fig:007 width=80% }

## Настройка доступа к файловому серверу

На маршрутизаторе **msk-donskaya-dgavadadev-gw-1** был дополнен список контроля доступа для организации доступа к файловому серверу.

Была выполнена следующая конфигурация:

ip access-list extended servers-out  
remark file  
permit tcp 10.128.0.0 0.0.255.255 host 10.128.0.3 eq 445  
permit tcp any host 10.128.0.3 range 20 ftp  

Данные правила разрешают узлам внутренней сети доступ к файловому серверу по протоколу SMB (порт 445), а также доступ по протоколу FTP для всех устройств.

## Контрольные вопросы

**1. Как задать действие правила для конкретного протокола?**  
Действие правила для конкретного протокола задаётся при создании записи в списке контроля доступа с указанием типа протокола. Например:

- `permit tcp any host 10.128.0.2 eq 80` — разрешает TCP-трафик  
- `permit udp any host 10.128.0.5 eq 53` — разрешает UDP-трафик  
- `permit icmp any any` — разрешает ICMP-запросы  

Таким образом, нужный протокол указывается непосредственно в правиле ACL.

**2. Как задать действие правила сразу для нескольких портов?**  
Для задания диапазона портов используется ключевое слово `range`. Например:

- `permit tcp any host 10.128.0.3 range 20 21` — разрешает доступ сразу к нескольким портам  

Также можно использовать несколько отдельных правил для разных портов, если требуется более точечная настройка.

**3. Как узнать номер правила в списке прав доступа?**  
Номер правила можно узнать с помощью команды:

- `show access-lists`  

В выводе команды каждому правилу присваивается порядковый номер, который отображается в начале строки.

**4. Каким образом можно изменить порядок применения правил в списке контроля доступа?**  
Порядок применения правил можно изменить, явно задав номер строки при добавлении правила. Например:

- `1 permit icmp any any`  

В этом случае правило будет помещено в начало списка. Также можно удалить правило и добавить его заново с нужным номером, чтобы изменить порядок выполнения ACL.
